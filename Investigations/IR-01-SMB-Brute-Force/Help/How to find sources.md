# Answer these questions. Fail any, and you should consider other sources.
## Is it about the incident?
- Is the company name correct?
- Is the event correct?
- Is the date correct?

## Can I trust the source?
- Who is the author (victim, gov, news, blog)?
- Does it show evidence of sources used?
- Are there warning signs (paywall, ai, ads)?

## Does this add value?
- Is it original (republish needs the same byline as original outlet; reporters need to be the same; need to quote the interview and not another blog)?
- say anything useful?

# Admiralty Code
## Source Trust
| Code | Status | Description |
| --- | --- | --- |
| A | Completely Reliable | Proven |
| B | Usually Reliable | Minor doubts |
| C | Fairly Reliable | Some valid past info |
| D | Not Usually Reliable | Occasionally correct |
| E | Unreliable | Consistently incorrect |
| F | Can't be judged | Insufficient history |

## Information Trust
| Code | Status | Description |
| --- | --- | --- |
| 1 | Confirmed | Independently corroborated |
| 2 | Probably True | Consistent with other facts |
| 3 | Possibly True | Not confirmed, somewhat consistent |
| 4 | Doubtful | No logic, lacks evidence |
| 5 | Improbable | Contradicted by other facts |
| 6 | Can't be judged | Insufficient evidence |
